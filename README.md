# E-Commerce Sales Analysis Using SQL

## Overview

An SQL project analyzing e-commerce data to understand **sales, customers, products, employees, orders and discounts**.

The goal was to turn raw sales data into simple business insights that can support better decisions.

## Objectives

* Analyze employee sales performance
* Identify high-value customers
* Track sales trends
* Analyze customer buying behaviour
* Identify high- and low-performing products
* Compare sales across countries and categories
* Analyze discounts and order sizes

## Tools

* MySQL
* MySQL Workbench
* SQL

## SQL Skills

`JOIN` · `GROUP BY` · `HAVING` · Aggregate Functions · `CASE` · CTEs · Subqueries · `RANK()` · `LAG()` · `PERCENT_RANK()` · Date Functions

## Key Findings

* Margaret Peacock recorded the highest sales at **$9,642**.
* Ernst Handel was the highest-value customer among the top five at **$3,642**.
* January 1997 sales were higher than February 1997.
* Gustaf's Knäckebröd recorded **700% sales growth**, while Inlagd Sill declined by **99.26%**.
* Some customers placed large-volume orders.
* Some products had very limited repeat orders.

## Recommendations

* Learn from top-performing employees to improve sales.
* Focus on retaining high-value customers.
* Keep fast-selling products well stocked.
* Review products with very low demand.
* Monitor discounts to ensure they support sales without reducing profit too much.

## Outcome

This project demonstrates my ability to use **SQL to analyze real-world business data, identify important patterns, and turn findings into clear business recommendations.**
